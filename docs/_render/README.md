# docs/_render — how the Jan Setu design artefacts are produced

Every diagram and wireframe in this project is **generated by a Python script**, so any
of them can be regenerated after a change instead of being redrawn by hand.

```
docs/_render/style.py            shared visual language — DO NOT EDIT
docs/_render/domain_facts.md     ground truth: entities, statuses, endpoints, taxonomy
docs/_render/render_*.py         one script per diagram family
docs/diagrams/*.png|.svg         SE diagrams   (PNG 300 dpi for Word, SVG for scaling)
docs/wireframes/*.png|.svg       UI wireframes
```

Run one: `cd docs/_render && python3 render_usecase.py`
Run all: `cd docs/_render && for f in render_*.py; do python3 "$f"; done`

## Conventions (non-negotiable — they are what makes the set look like one document)

1. **matplotlib only.** Import every primitive from `style.py`. Do not use Graphviz,
   Mermaid or PlantUML: mixing toolchains produces mismatched fonts and colours.
2. **Do not edit `style.py`.** If you need a new primitive, define it as a local helper
   at the top of your own `render_*.py`, built from `style.py` pieces.
3. **Never touch application code** (`backend/`, `frontend/`, `v2/`). These scripts are
   documentation; they only read `domain_facts.md`.
4. **Semantic colours are fixed:** `CITIZEN` blue = citizen-facing, `OFFICER` green =
   field officer, `SUPERVISOR` brown = supervision/escalation, `ADMIN` purple =
   analytics/administration, `AI` rust = agent/AI service, `STORE` slate = data store,
   `EXTERNAL` grey = third-party system.
5. **Coordinate space** is `0..100` in x and `0..100*H/W` in y, and **y grows downward**
   (`canvas()` inverts the axis) so scripts read like a page: small y = top.
6. Each script exposes `build()` returning the `(png, svg)` paths and ends with
   `if __name__ == "__main__": print("wrote", *build())`.
7. Every diagram carries a `note(...)` footnote explaining how to read it, and a
   `legend(...)` when it uses more than two colours.
8. Leave whitespace. A connector must never cross a text label. Reserve ~4 units of
   clear gutter between columns and route long connectors down a gutter, not over boxes.

## `style.py` API

```python
canvas(w, h, title=None, subtitle=None) -> (fig, ax)
save(fig, name, folder=None) -> (png_path, svg_path)      # folder: DIAGRAMS or WIREFRAMES

box(ax, x, y, w, h, label, *, fill, edge, fs, radius=0.9, lw, bold, text_colour, ls, va)
sharp(ax, x, y, w, h, label, *, fill, edge, fs, lw, bold, text_colour, ls)
store(ax, x, y, w, h, label, *, edge=STORE, fs)           # Gane–Sarson data store
actor(ax, x, y, label, *, colour, scale, fs, below=True)  # x,y = centre of the head
arrow(ax, p0, p1, *, colour, lw, style="-|>", ls, rad, label, label_pos, fs,
      label_dy, label_dx, label_bg, ms, zorder)
group(ax, x, y, w, h, label, *, edge, fill, fs, ls)       # dashed frame, label top-left
legend(ax, [(colour, text), ...], x, y, *, fs, gap=3.1, title=None)
note(ax, x, y, w, text, *, fs, colour)                    # footnote paragraph
tint(hex_colour, amount=0.90)                             # lighten toward white
```
`box`/`sharp`/`store`/`group` take **x,y = top-left**. Constants available:
`INK INK_SOFT LINE LINE_FAINT PAPER CANVAS CITIZEN OFFICER SUPERVISOR ADMIN AI STORE
EXTERNAL FS_TITLE FS_SUB FS_HEAD FS_BODY FS_SMALL FS_TINY DIAGRAMS WIREFRAMES`.
